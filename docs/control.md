# Контрольный этап: 8 ноября, 11:00

Claude Code для этого не нужен: всё делается через сайт.

## 1. Запустить сервер, если он не запущен

Откройте терминал Ubuntu (WSL) и выполните:

```bash
~/doomsday/scripts/start.sh
```

Окно не закрывайте. Откройте в браузере http://localhost:8000

## 2. Загрузить и оценить контрольные диалоги

1. Вкладка **Диалоги**: в поле `group_id` введите значение от организаторов и нажмите **Загрузить набор**.
2. В фильтре наборов останутся все диалоги. Отметьте галочками новые 10 диалогов: в колонке «Набор» у них ваш `group_id`.
3. Нажмите **Оценить выбранные**. Статус обновится сам, оценка одного диалога занимает около минуты.
4. Если у диалога статус **Ошибка**, откройте его и нажмите **Оценить заново**.

## 3. Замена критерия

1. Вкладка **Чек-лист**: измените или добавьте критерий, затем нажмите **Сохранить новую версию**.
2. Вкладка **Диалоги**: выберите новую версию чек-листа рядом с кнопками оценки и запустите оценку нужных диалогов.

## 4. Выгрузить результаты и сделать push (до 12:00)

Организаторы проверяют файл `results/prod/results.json` в репозитории. Локального файла или коммита без push недостаточно.

В терминале Ubuntu (WSL), где `<group_id>` — значение от организаторов:

```bash
cd ~/doomsday
.venv/bin/python -m scripts.export_results <group_id> prod
git add results && git commit -m "Add prod results" && git push
```

Скрипт напишет число записей. В prod их должно быть ровно 10. Неоценённые диалоги попадают в файл со `status: "error"`, это допустимо. Если ошибки есть и время ещё остаётся, оцените такие диалоги заново и выгрузите файл повторно.

Выгружаются ответы модели без правок человека, то есть результат работы системы.

## Если закончился лимит Claude

1. Получите бесплатный ключ на openrouter.ai.
2. В файле `~/doomsday/.env` поставьте `LLM_PROVIDER=openrouter` и `OPENROUTER_API_KEY=ваш_ключ`.
3. Перезапустите сервер: в окне сервера нажмите Ctrl+C и снова выполните `~/doomsday/scripts/start.sh`.

Звонки через OpenRouter не отправляются, это защита персональных данных. Их можно оценить только через Claude.
